# Проектная работа «Медиаплан»

Делайн сдачи проекта — 19 октября 2026 года, 12.00 мск

В этом модуле вам откроются новые данные для проектной работы. Они понадобятся, чтобы продолжить работу над проектом и выполнить следующие задания.

Переведите маркетинговую стратегию в конкретный план: распределите бюджет по каналам и рассчитайте ожидаемые результаты.

### Что нужно сделать

1. Распределите годовой маркетинговый бюджет по каналам.
2. Для каждого канала укажите стадию воронки.
3. Рассчитайте KPI по каналам с помощью бенчмарков: сколько лидов и MQL может принести каждый канал при заданном бюджете.
4. Определите микроконверсии, например скачивание гайда, регистрацию на вебинар, использование ROI-калькулятора, просмотр демо-видео или запрос демо.
5. Составьте медиаплан на год.

Используйте новые данные, а также данные из предыдущих работ и бенчмарки из этого модуля. Если каких-то данных не хватает, сформулируйте и зафиксируйте предположение.
