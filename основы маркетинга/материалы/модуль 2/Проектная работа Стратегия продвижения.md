# Проектная работа «Стратегия продвижения»

Дедлайн сдачи проекта — 5 октября 2026 года, 12:00 мск.

В новом модуле «Разработка маркетинговой стратегии» вы продолжите работать с кейсом из прошлого модуля. Для проектной работы вам будут доступны новые данные. Выполните её в [предложенном шаблоне](https://disk.yandex.ru/d/R25BUyKUfId15A).

**Что нужно сделать**

1. Выберите модель роста. Рассчитайте, сколько сделок, SQL и MQL потребуется, чтобы увеличить новый ARR на 30%. Используйте текущие конверсии воронки.
2. Определите, за счёт чего расти. Сравните два варианта: привлекать больше лидов или повышать конверсию MQL → SQL и точечно работать с крупными аккаунтами (ABM). Обоснуйте выбор с точки зрения экономики. Проверьте расчёты самостоятельно и с помощью ИИ. Добавьте в шаблон промпт, модель, результат и выводы.
3. Оцените юнит-экономику. Рассчитайте `CAC payback` и `LTV/CAC`. Оцените, насколько здорова текущая экономика и в каком направлении её нужно развивать. Проверьте расчёты самостоятельно и с помощью ИИ. Добавьте в шаблон промпт, модель, результат и выводы.
4. Спроектируйте воронку. Учтите длинный цикл: demand gen → lead gen → MQL → SQL → демо → сделка. Обоснуйте, какой канал работает на каждом этапе.

**Подсказка**: конверсия из MQL в сделку составляет около 2,7%. Поэтому рост можно обеспечить не только за счёт новых лидов, но и за счёт повышения конверсии на каждом этапе воронки. Часто второй вариант обходится дешевле.

## **Что нужно сдать**

Подготовьте презентацию «Стратегия продвижения». В ней должны быть:

1. Модель роста — расчёт по воронке и показатели, необходимые для достижения цели.
2. Юнит-экономика — расчёты `LTV/CAC` и `CAC payback` (только для B2B).
3. Воронка — целевые показатели по её этапам.
4. Каналы продвижения — выбор каналов и обоснование их роли в воронке.
5. Креативная концепция — единое сообщение для коммуникации (только для B2C).
6. Результаты работы с ИИ.

Требование к сдаче проекта

Презентация должна быть в формате PDF. Проектная работа сдаётся архивом и должна содержать результаты работы с ИИ.
