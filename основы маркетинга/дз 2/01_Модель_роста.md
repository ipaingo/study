# 1. Модель роста

## Исходные данные кейса

| Параметр               | Значение                      |
| ---------------------- | ----------------------------- |
| Текущий ARR            | 600 млн руб.                     |
| Клиентов               | ≈400                          |
| Средний контракт (ACV) | 1,5 млн руб./год                 |
| Цель                   | +30% нового ARR за 12 месяцев |
| Цикл сделки            | 3,5 мес                       |
| Ограничение            | CAC payback ≤ 12 мес          |

## Декомпозиция цели

- Цель в деньгах: 600 млн × 30% = **+180 млн руб. нового ARR**.
- В сделках: 180 млн / 1,5 млн = **120 новых сделок/год (10/мес)** – совпадает с оценкой из ДЗ 1 (SMART-задача).

## Текущие конверсии воронки

Подсказка задания: сквозная конверсия MQL → сделка ≈ 2,7%. Раскладываем ее на этапы (все значения в пределах бенчмарков B2B SaaS):

| Переход          | Конверсия                     |
| ---------------- | ----------------------------- |
| MQL → SQL        | 15%                           |
| SQL → демо       | 45%                           |
| Демо → сделка    | 40%                           |
| **MQL → сделка** | **0,15 × 0,45 × 0,40 = 2,7%** |

Допущение: конверсия лид → MQL = 30% (бенчмарк B2B SaaS для входящего трафика из контента и контекстной рекламы).

## Расчет объемов по этапам (сценарий А – текущие конверсии)

Идем от цели снизу вверх:

| Этап | Расчет | В год | В месяц |
|---|---|---|---|
| Сделки | 180 млн / 1,5 млн | **120** | 10 |
| Демо | 120 / 0,40 | **300** | 25 |
| SQL | 300 / 0,45 | **667** | 56 |
| MQL | 667 / 0,15 | **4 444** | 370 |
| Лиды | 4 444 / 0,30 | **≈14 800** | ≈1 235 |

## Вывод

Чтобы выполнить план только за счет объема, нужно вырасти с текущего уровня до **370 MQL/мес и ~56 SQL/мес**. Учитывая узкий горячий спрос (по кейсу запросов типа "купить WMS" мало) и дорожающий платный трафик, это самый дорогой путь. Поэтому дальше сравниваем его со сценарием роста конверсии (см. 02_Сценарии_роста.md).
