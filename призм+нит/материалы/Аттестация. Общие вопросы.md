## Аттестация: общие вопросы

Здесь размещена общая информация по обоим трекам, в которой описывается организация защиты и процесс подготовки документации. Требования к документации и более подробные рекомендации подготовки по обоим трекам приводятся в соответствующем разделе.

Аттестация по НИР3 включает в себя:

- промежуточную презентацию;
- отчет.

Зачет складывается из оценивания обеих частей

Оценивание осуществляется по критериям по 10-балльной шкале. В следующих юнитах будут приведены критерии оценивания по каждому треку.

#### Промежуточная презентация

|   |   |
|---|---|
|**Дедлайн**|Октябрь — ноябрь|
|**Формат**|Синхронный|
|**Тайминг выступления**|Стартап:<br><br>4 мин. — общие слайды проекта<br><br>5 мин. — индивидуальные слайды каждого участника<br><br>8 мин. — вопросы и замечания комиссии|
|Исследование:<br><br>7 мин. — выступление<br><br>5 мин. — вопросы и замечания комиссии|

**Особенность:** комиссия оценивает наличие и качество представленных документов, делает замечания и дает рекомендации в устной форме. Студенту необходимо внимательно слушать замечания от экспертов

**До выступления с промежуточной презентацией настоятельно рекомендуется:**

- Показать и обсудить презентацию с научным руководителем. Получить от научного руководителя обратную связь и скорректировать презентацию.
- Отрепетировать выступление с учетом тайминга. Соблюсти тайминг очень важно, в противном случае вам не удастся раскрыть все ключевые моменты в своем выступлении, так как оно будет прервано модератором.

**Оценивание презентации:**

- Если среднее количество баллов < 3 баллов или по решению комиссии, — презентация не зачтена.
- Если по одному из критериев оценивания презентация набирает < 3 баллов или по решению комиссии — отчет студента в любом случае попадает на аудит (декабрь).
- Во всех иных случаях — зачтено.

Если студент не явился на промежуточные презентации, он направляется на пересдачу.

Если студент не явился на промежуточную ситуацию и научный руководитель подтверждает, что студент не работает над исследованием и не выполняет предусмотренные задания, студент может быть отчислен за недобросовестное освоение образовательной программы в соответствии с Положением о текущем контроле успеваемости и промежуточной аттестации обучающихся МФТИ.

#### Отчет

|   |   |
|---|---|
|**Дедлайн**|Декабрь|
|**Формат**|Асинхронный|

**Оценивание отчета:**

- Если по итогам промежуточной презентации был назначен аудит, то отчет проходит процедуру аудита.
- Если по итогам аудита отчета хотя бы по одному из критериев оценивания < 3 баллов, это означает, что студент получает незачет.
- Если по итогам аудита отчета среднее количество баллов < 3 баллов, означает, что студент получает незачет.
- Если по итогам промежуточной презентации аудит не был назначен, то комиссия смотрит баллы, выставленные научным руководителем. Если хотя бы по одному из критериев научный руководитель поставил < 3 баллов, то студент получает незачет.
- Во всех остальных случаях — зачтено.

Если студент не сдал вовремя отчет с подписью научного руководителя, это оценивается как неявка на НИР.

#### Что такое аудит

Аудит — это процедура оценивания, при которой проверку презентации и отчета студента осуществляют эксперты Центра «Пуск».

#### Как проходит пересдача

Пересдача проходит в феврале в синхронном формате. Студент представляет свой отчет и выступает с презентацией.
